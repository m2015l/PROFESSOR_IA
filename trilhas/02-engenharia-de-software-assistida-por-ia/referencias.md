## 2. Capítulos Complementares para Consulta Sob Demanda

- **Em *Beyond Vibe Coding* (Addy Osmani):**
  - **Capítulo 6 (*AI-Driven Prototyping: Tools and Techniques*, pp. 109–120):** Estratégias para criar protótipos funcionais de validação rápida de produto (MVP) e critérios para decidir entre refatorar ou reescrever o protótipo ao migrar para produção.
  - **Capítulo 7 (*Building Web Applications with AI*, pp. 121–140):** Estruturação de aplicações web full-stack, definição de esquemas de banco de dados e integração entre frontend e backend com suporte de IA.
  - **Capítulo 11 (*Beyond Code Generation: The Future of AI-Augmented Development*, pp. 205–224):** Automação de manutenção contínua, triagem de incidentes e evolução de fluxos de engenharia de software.

- **Em *AI-Assisted Programming* (Tom Taulli):**
  - **Capítulo 2 (*How AI Coding Technology Works*, pp. 21–42):** Visão geral sobre tokenização de código, arquiteturas Transformer aplicadas a linguagens de programação e métricas de avaliação de modelos geradores de código (como HumanEval).
  - **Capítulos 4 e 5 (*GitHub Copilot* e *Other AI-Assisted Programming Tools*, pp. 61–102):** Panorama comparativo histórico de extensões de autocompletar em IDEs e ferramentas low-code/no-code.
